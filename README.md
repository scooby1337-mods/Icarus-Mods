# Icarus Mods by scooby1337

Mods for [Icarus](https://store.steampowered.com/app/1149460/ICARUS/), available in the
**Icarus Mod Manager** (IMM) database and on Nexus Mods.

| Mod | Description | Nexus |
|---|---|---|
| ![](Ore_Overhaul.jpg) **Ore Overhaul** | Minable Lithium and Ruby ore on Olympus, Styx and Prometheus | [Link](https://www.nexusmods.com/icarus/mods/351) |
| ![](Synthetic_Miasma.jpg) **Synthetic Miasma** | Craft Crystallised Miasma at the Chemistry Bench on maps without a swamp | [Link](https://www.nexusmods.com/icarus/mods/376) |

## Installation
In IMM: refresh the online database, select the mod, download/extract it and merge it with your other mods.
Manual `.pak` downloads are on the Nexus pages.

`modinfo.json` in this repository is read by the IMM mod database.
